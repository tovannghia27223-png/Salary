Bảng lương & KPI — Thiết kế Configurable cho mọi công ty

Xây dựng một lần, điều chỉnh linh hoạt. Không cần sửa code khi chuyển công ty hay thay đổi chính sách lương.

01

Tổng quan kiến trúc

Thay vì hard-code công thức lương và KPI, bạn cần một hệ thống configuration-driven: dữ liệu định nghĩa cách tính, code chỉ đọc và thực thi.

Configuration Layer

Các bảng cấu hình: công thức lương, bộ KPI theo chức danh, thang điểm, ngưỡng thưởng. Chỉnh sửa = UPDATE database, không cần deploy code.

Data Layer

Dữ liệu nhân viên, chấm công, KPI thực tế, bảng lương từng kỳ. Lưu lịch sử để audit và so sánh theo thời gian.

Engine Layer

Code tính toán đọc config và data, output bảng lương. Công thức viết dưới dạng expression có thể parse (JSON/DSL).

Presentation Layer

UI hiển thị bảng lương, biểu đồ KPI, báo cáo. Tách biệt hoàn toàn với logic tính toán.

i
Triết lý thiết kế: Mọi quy tắc tính lương, KPI, thuế, bảo hiểm đều phải lưu trong database dưới dạng config. Khi bn chuyển sang công ty mới, chỉ cần import config mới — code giữ nguyên.
02

Database Schema (Supabase/PostgreSQL)

Dưới đây là các bảng cần thiết, thiết kế để dễ dàng điều chỉnh trong tương lai.

2.1. Bảng Cấu hình — Lương

SQL — salary_components (Các khoản lương) CREATE TABLE salary_components ( id SERIAL PRIMARY KEY, code TEXT NOT NULL UNIQUE, -- 'BASE_SALARY', 'KPI_BONUS', 'LUNCH_ALLOWANCE'... name_vi TEXT NOT NULL, -- 'Lương cơ bản' name_en TEXT, -- 'Base Salary' type TEXT NOT NULL CHECK (type IN ('fixed','variable','allowance','deduction','tax','insurance')), is_taxable BOOLEAN DEFAULT FALSE, -- Có tính thuế TNCN không is_insurable BOOLEAN DEFAULT FALSE, -- Có tính đóng BHXH không is_visible BOOLEAN DEFAULT TRUE, -- Hiển thị trên phiếu lương sort_order INTEGER DEFAULT 0, -- Thứ tự hiển thị formula_expr TEXT, -- Công thức JS expression, NULL = nhập tay active BOOLEAN DEFAULT TRUE, created_at TIMESTAMPTZ DEFAULT NOW() ); -- Ví dụ insert INSERT INTO salary_components (code, name_vi, type, is_taxable, is_insurable, sort_order, formula_expr) VALUES ('BASE_SALARY', 'Lương cơ bản', 'fixed', true, true, 10, NULL), -- Nhập tay từ hợp đồng ('LUNCH_ALLOWANCE', 'Phụ cấp ăn trưa', 'allowance', false, false, 20, '730000'), -- Cố định 730k ('KPI_BONUS', 'Thưởng KPI', 'variable', true, false, 30, NULL), -- Tính từ bảng kpi_results ('BHXH_EE', 'BHXH (8%)', 'insurance', false, false, 100, '-BASE_SALARY * 0.08'), ('BHYT_EE', 'BHYT (1.5%)', 'insurance', false, false, 101, '-BASE_SALARY * 0.015'), ('BHTN_EE', 'BHTN (1%)', 'insurance', false, false, 102, '-BASE_SALARY * 0.01');

2.4. Bảng KPI — Kết quả thực tế

SQL — kpi_results (Kết quả KPI từng kỳ) CREATE TABLE kpi_results ( id SERIAL PRIMARY KEY, user_id UUID NOT NULL REFERENCES auth.users, period TEXT NOT NULL, -- '2024-01', '2024-Q1', '2024' period_type TEXT NOT NULL CHECK (period_type IN ('month','quarter','year')), kpi_template_id INTEGER REFERENCES kpi_templates, kpi_code TEXT NOT NULL, target_value NUMERIC, -- Mục tiêu actual_value NUMERIC, -- Thực tế achievement_pct NUMERIC, -- actual / target * 100 weighted_score NUMERIC, -- achievement_pct * weight evidence_url TEXT, -- Link minh chứng evaluator_id UUID REFERENCES auth.users, -- Người đánh giá evaluated_at TIMESTAMPTZ, status TEXT DEFAULT 'draft' CHECK (status IN ('draft','submitted','approved','disputed')), note TEXT, created_at TIMESTAMPTZ DEFAULT NOW(), UNIQUE (user_id, period, kpi_code) );

2.5. Bảng Bảng lương

SQL — payroll_records (Bảng lương từng kỳ) CREATE TABLE payroll_records ( id SERIAL PRIMARY KEY, user_id UUID NOT NULL REFERENCES auth.users, period TEXT NOT NULL, -- '2024-01' base_salary NUMERIC NOT NULL, -- Lương cơ bản items JSONB NOT NULL DEFAULT '[]', -- [{component_code, amount, note}, ...] gross_salary NUMERIC, -- Tổng trước khấu trừ total_deduction NUMERIC, -- Tổng khấu trừ tax_amount NUMERIC, -- Thuế TNCN net_salary NUMERIC, -- Thực nhận formula_used JSONB, -- Snapshot công thức đã dùng status TEXT DEFAULT 'draft' CHECK (status IN ('draft','calculated','locked','paid')), locked_by UUID REFERENCES auth.users, locked_at TIMESTAMPTZ, created_at TIMESTAMPTZ DEFAULT NOW(), UNIQUE (user_id, period) );
OK
Ưu điểm của thiết kế này: Khi chuyển sang công ty mới, bạn chỉ cn INSERT config mới vào salary_components, payroll_formulas, kpi_definitions, kpi_templates. Code JavaScript tính lương giữ nguyên 100%.

Code JavaScript — Engine tính lương

Engine đọc config từ database, tính toán và lưu kết quả. Code này không cần sửa khi đổi công ty.

4.1. Hàm tính lương GROSS → NET

JavaScript — payrollEngine.js /** * Tính bảng lương cho 1 nhân viên 1 kỳ * @param {Object} config — từ bảng payroll_formulas + salary_components * @param {Object} data — lương CB, phụ cấp, KPI, chấm công... * @returns {Object} — chi tiết từng khoản + net_salary */ async function calculatePayroll(userId, period, supabase) { // 1. Lấy config hiện hành const { data: components } = await supabase .from('salary_components') .select('*') .eq('active', true) .order('sort_order'); const { data: formula } = await supabase .from('payroll_formulas') .select('*') .eq('formula_type', 'salary') .eq('active', true) .lte('effective_from', period + '-01') .or(`effective_to.is.null,effective_to.gte.${period}-01`) .single(); // 2. Lấy dữ liệu nhân viên const { data: salary } = await supabase .from('salaries') .select('*') .eq('user_id', userId) .single(); // 3. Tính từng khoản const context = { BASE_SALARY: salary?.sal || 0, ALLOWANCE: salary?.al || 0, KPI_BONUS: await calculateKPIBonus(userId, period, supabase), PERIOD: period, }; const items = components.map(comp => { let amount = 0; if (!comp.formula_expr) { // Nhập tay hoặc lấy từ context amount = context[comp.code] || 0; } else { // Đánh giá expression an toàn amount = safeEval(comp.formula_expr, context); } return { component_code: comp.code, component_name: comp.name_vi, type: comp.type, amount: Math.round(amount), }; }); // 4. Tổng hợp const gross = items.filter(i => ['fixed','variable','allowance'].includes(i.type)) .reduce((s, i) => s + i.amount, 0); const deductions = items.filter(i => ['deduction','insurance','tax'].includes(i.type)) .reduce((s, i) => s + i.amount, 0); const tax = calculateTax(gross, supabase); // Tính thuế theo biểu lũy tiến config const net = gross + deductions + tax; // deductions & tax đã âm // 5. Lưu vào payroll_records await supabase.from('payroll_records').upsert({ user_id: userId, period: period, base_salary: context.BASE_SALARY, items: items, gross_salary: gross, total_deduction: deductions, tax_amount: tax, net_salary: net, formula_used: formula?.config_json, status: 'calculated', }); return { items, gross, deductions, tax, net }; } // Đánh giá expression an toàn — KHÔNG dùng eval() function safeEval(expr, context) { // Chỉ cho phép số, toán tử + - * / ( ), và biến từ context const vars = Object.keys(context).join(','); const vals = Object.values(context); const fn = new Function(vars, `return (${expr})`); return fn(...vals); }

4.2. Hàm tính thuế TNCN (configurable)

JavaScript — taxEngine.js // Bảng thuế lũy tiến — lưu trong DB, có thể cập nhật khi luật thay đổi // Bậc 1: đến 5tr: 5% | Bậc 2: 5-10tr: 10% | Bậc 3: 10-18tr: 15% ... async function calculateTax(taxableIncome, supabase) { const { data: brackets } = await supabase .from('tax_brackets') .select('*') .eq('active', true) .order('bracket_order'); let remaining = taxableIncome; let tax = 0; for (const b of brackets) { const range = b.upper_bound ? (b.upper_bound - b.lower_bound) : Infinity; const taxable = Math.min(remaining, range); tax += taxable * b.rate; remaining -= taxable; if (remaining <= 0) break; } return -Math.round(tax); // Trả về số âm (khấu trừ) } // SQL tạo bảng tax_brackets /* CREATE TABLE tax_brackets ( id SERIAL PRIMARY KEY, bracket_order INT NOT NULL, lower_bound NUMERIC NOT NULL, upper_bound NUMERIC, -- NULL = trở lên rate NUMERIC NOT NULL, -- 0.05, 0.10, 0.15... description TEXT, active BOOLEAN DEFAULT TRUE, effective_from DATE DEFAULT '2020-07-01' ); */

Code JavaScript — Engine tính KPI

Engine đọc KPI template, tính điểm và xếp loại. Hỗ trợ 4 phương pháp: Linear, Tiered, Matrix, OKR.

5.1. Hàm tính KPI tổng hợp

JavaScript — kpiEngine.js async function calculateKPIBonus(userId, period, supabase) { // 1. Lấy KPI results đã nhập const { data: results } = await supabase .from('kpi_results') .select('*, kpi_templates(kpi_items)') .eq('user_id', userId) .eq('period', period) .eq('status', 'approved'); if (!results?.length) return 0; // 2. Lấy công thức KPI hiện hành const { data: kpiFormula } = await supabase .from('payroll_formulas') .select('*') .eq('formula_type', 'kpi') .eq('active', true) .lte('effective_from', period + '-01') .order('effective_from', { ascending: false }) .limit(1) .single(); const cfg = kpiFormula?.config_json || { method: 'linear', base_bonus_pct: 0.20 }; // 3. Tính tổng điểm KPI const totalScore = results.reduce((sum, r) => sum + (r.weighted_score || 0), 0); // 4. Lấy lương cơ bản để tính thưởng KPI tối đa const { data: sal } = await supabase .from('salaries') .select('sal') .eq('user_id', userId) .single(); const baseSalary = sal?.sal || 0; const maxBonus = baseSalary * (cfg.base_bonus_pct || 0.20); // 5. Áp dụng phương pháp tính let bonus = 0; switch (cfg.method) { case 'linear': bonus = maxBonus * (totalScore / 100); break; case 'tiered': bonus = applyTieredFormula(totalScore, maxBonus, cfg.tiers); break; case 'matrix': bonus = await applyMatrixFormula(userId, period, maxBonus, cfg, supabase); break; case 'okr': bonus = await applyOKRFormula(userId, period, maxBonus, cfg, supabase); break; default: bonus = maxBonus * (totalScore / 100); } // 6. Áp giới hạn nếu có if (cfg.cap_multiplier) { bonus = Math.min(bonus, maxBonus * cfg.cap_multiplier); } return Math.round(bonus); } // === Phương pháp Bậc thang === function applyTieredFormula(score, maxBonus, tiers) { for (const tier of tiers || []) { if (score >= tier.min && score <= tier.max) { return maxBonus * tier.factor; } } return 0; } // === Phương pháp Ma trận (cá nhân + bộ phận + công ty) === async function applyMatrixFormula(userId, period, maxBonus, cfg, supabase) { let weightedBonus = 0; for (const comp of cfg.components || []) { let score = 0; if (comp.type === 'individual_kpi') { const { data } = await supabase.from('kpi_results') .select('weighted_score') .eq('user_id', userId).eq('period', period); score = data?.reduce((s, r) => s + r.weighted_score, 0) || 0; } else if (comp.type === 'dept_kpi') { score = await getDepartmentKPIScore(userId, period, supabase); } else if (comp.type === 'company_kpi') { score = await getCompanyKPIScore(period, supabase); } weightedBonus += maxBonus * comp.weight * (score / 100); } // Áp hệ số công ty const companyFactor = await getCompanyFactor(period, cfg.company_factor, supabase); return weightedBonus * companyFactor; }

5.2. Hàm xếp loại & snapshot

JavaScript — kpiGrade.js // Xếp loại dựa trên config trong payroll_formulas function getKPIGrade(score, gradeMap) { const grades = ['A', 'B', 'C', 'D', 'E']; for (const grade of grades) { if (score >= (gradeMap[grade]?.min_score || 0)) { return { grade, label: gradeMap[grade]?.label || grade }; } } return { grade: 'E', label: 'Chưa đạt' }; } // Snapshot kết quả KPI để lưu vào payroll_records async function snapshotKPIResults(userId, period, supabase) { const { data: results } = await supabase .from('kpi_results') .select('kpi_code, target_value, actual_value, achievement_pct, weighted_score') .eq('user_id', userId) .eq('period', period) .eq('status', 'approved'); const totalScore = results?.reduce((s, r) => s + r.weighted_score, 0) || 0; const { data: formula } = await supabase .from('payroll_formulas') .select('config_json') .eq('formula_type', 'kpi') .eq('active', true) .single(); const gradeMap = formula?.config_json?.grade_map || {}; const { grade, label } = getKPIGrade(totalScore, gradeMap); return { kpi_details: results, total_score: Math.round(totalScore * 100) / 100, grade, grade_label: label, calculated_at: new Date().toISOString(), }; }
